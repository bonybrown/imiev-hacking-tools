# 0x101

| Field          | Value              |
|----------------|--------------------|
| **Sender**     | EV-ECU             |
| **Recipients** | ETACS              |
| **Period**     | Transition-driven  |
| **Length**     | 1                  |

Immobiliser state byte from the EV-ECU. In the captures seen so far, this message appears only when the state changes rather than as a free-running periodic status frame.

---

## Signals

| Byte | Signal               | Notes |
|------|----------------------|-------|
| 0    | Immobiliser state    | Exact semantics unknown; observed values listed below |

## Observed values

| Value  | Interpretation |
|--------|----------------|
| `0x00` | Baseline or idle state |
| `0x01` | Ready to accept handshake request state |
| `0x04` | Accepted/unlocked state after valid [0x111](111.md) response |

## Observed transition sequence

During a successful handshake, the observed sequence is:

```text
00 -> 01 -> 00 -> 04
```

The only additional observed transition so far is:

```text
04 -> 00
```

when the key is turned off.
