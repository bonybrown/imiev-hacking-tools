# 0x149

| Field          | Value   |
|----------------|---------|
| **Sender**     | ABS/ESC |
| **Recipients** | EV-ECU  |
| **Period**     | 20 ms   |
| **Length**     | 8       |

Yaw rate and lateral acceleration from the ABS/ESC unit. The EV-ECU copies bytes 0–5 to an internal buffer and computes scaled floating-point values. A raw value of `0xFFFF` signals an invalid reading; the validity flag bit is set and the last known good value is retained.
