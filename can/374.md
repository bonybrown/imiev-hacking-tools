# 0x374

| Field          | Value                    |
|----------------|--------------------------|
| **Sender**     | BMU                      |
| **Recipients** | EV-ECU                   |
| **Period**     | 100 ms                   |
| **Length**     | 8                        |

Battery state of charge, cell temperatures and full-charge capacity from the BMU.

Example frames from the PID definition YAML:

- `B0B300004A483D00`
- `8E9100004B4A3D00`

---

## Signals

| Byte | Bits | Signal                         | Type     | Scale | Offset | Unit | Notes |
|------|------|--------------------------------|----------|-------|--------|------|-------|
| 0    | 7:0  | Battery SOC 1                  | uint8    | 0.5   | −10    | %    |       |
| 1    | 7:0  | Battery SOC 2                  | uint8    | 0.5   | −10    | %    |       |
| 2–3  | 15:0 | Unused                        | uint16   | —     | —      | —    | The 9499B115 firmware does not set these bytes at all when sending this message.      |
| 4    | 7:0  | Maximum cell temperature      | uint8    | 1     | −50    | °C   |       |
| 5    | 7:0  | Minimum cell temperature      | uint8    | 1     | −50    | °C   |       |
| 6    | 7:0  | Battery full capacity         | uint8    | 0.5   | 0      | Ah   | Capacity at 100% SOC |
| 7    | 7:1  | Unknown                        | uint7    | —     | —      | —    |       |
| 7    | 0    | Battery cooling fan running   | 1-bit flag | —   | —      | —    | 1 when the battery pack cooling fan is running |

For the scaled signals, the physical value is calculated as:

$$
\text{value} = \text{raw} \times \text{scale} + \text{offset}
$$

The YAML definition does not specify a separate byte order for the one-byte signals. `Battery SOC 2` has no explicit `start_bit` in the YAML, but follows `Battery SOC 1` at byte 1.
