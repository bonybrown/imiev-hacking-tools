# 0x418

| Field          | Value   |
|----------------|---------|
| **Sender**     | EV-ECU  |
| **Recipients** | ?       |
| **Period**     | 20 ms   |
| **Length**     | 7       |

Gear shift lever position from the EV-ECU.

---

## Signals

| Byte | Signal              | Notes                        |
|------|---------------------|------------------------------|
| 0    | Shift lever position | See values below; `0xFF` = invalid |
| 1–6  | -                   | Not set by the EV-ECU, alwayts zero                             |

### Shift lever position values

| Value  | Position |
|--------|----------|
| `0x20` | unset    |
| `0x50` | P        |
| `0x52` | R        |
| `0x4E` | N        |
| `0x44` | D        |
| `0x83` | B        |
| `0x32` | C        |
| `0xFF` | Invalid  |


Note that the B and C positions do not match
the ASCII character values as the others do.
