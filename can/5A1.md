# 0x5A1

| Field       | Value                        |
|-------------|------------------------------|
| **Sender**  | BMU                          |
| **Recipients** | EV-ECU                    |
| **Period**  | 50ms                         |
| **Length**  | 8                            |

BMU condition status bits. Each byte carries up to four 2-bit status fields. The 2-bit encoding reflects the active/stored state of the corresponding fault.

* The MSB of the pair is the active state (1 = fault active now)
* The LSB of the pair is the stored state (1 = fault has occurred)

_BOTH_ bits are set when the fault is occurring now.

bits on the DTCs raised by the EV-ECU.

They are not the DTCs that the BMU may raise
as a result of the condition.
